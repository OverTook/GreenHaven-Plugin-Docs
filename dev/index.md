# 개발자

게임 밖에서 GreenHaven 서버와 이야기하는 프로그램(봇, 서버 목록 사이트, 다른 클라이언트, 운영 도구)을 만드는 분을 위한
문서예요.

| 문서 | 내용 |
|---|---|
| [네트워크 프로토콜](protocol) | 연결, 접속, 행동과 답, 서버 메시지, 데이터그램, 청크 형식 |

서버의 규칙·콘텐츠·월드를 바꾸는 것은 [플러그인](/plugins/)이에요. 플러그인은 서버에 폴더 하나를 넣으면 되고, 접속하는
사람은 아무것도 설치하지 않아요.

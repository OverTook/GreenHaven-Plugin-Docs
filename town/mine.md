# 광산
{: .no_toc }

마을 아래로 끝없이 이어지는 광산입니다. 입구의 방에서 수직 갱도를 타고 내려갑니다.

- **층은 매일 아침 새로 만들어집니다.** 부순 돌도 다음 날이면 다시 생깁니다.
- 각 층의 사다리로 내려가고, 사다리로 입구까지 돌아옵니다.
- **엘리베이터는 5층마다** 있어서 내려가 본 가장 깊은 곳까지 갈 수 있습니다.
- **10층마다 쉼터**입니다. 돌과 몬스터가 없고 불이 있습니다.
- 광산에서는 점프할 수 없습니다.

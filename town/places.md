## 장소

| 장소 | 분류 | 설명 |
|---|---|---|
| 내 농장 | 농장 | 내가 가꾸는 농장. 밭과 집, 우체통, 출하함이 있어요. |
| 내 헛간 | 농장 | 서연이 지어 준 헛간과 우리. 소와 양, 돼지가 지내요. |
| 내 닭장 | 농장 | 서연이 지어 준 닭장과 우리. 닭이 지내요. |
| 민재네 목장 | 농장 | 민재가 소와 양, 닭을 키우는 목장. 집 앞 우리에서 동물들이 풀을 뜯어요. |
| 해솔네 밭 | 농장 | 해솔이 집 앞에서 가꾸는 큰 밭. 마을 사람들이 먹는 채소가 여기서 나요. |
| 잡화점 | 상점 | 씨앗, 묘목, 사료, 장비와 나침반을 사고 물건을 팔아요. |
| 대장간 | 상점 | 도구와 무기를 한 등급 위로 강화해 줘요 (돌 → 구리 → 철 → 금 → 미스릴). |
| 진료소 | 시설 | 기력과 체력을 회복하는 약을 팔아요. |
| 도서관 | 시설 | 광물과 물고기를 기증해 전시실을 채워요. 다섯 점마다 사례가 있어요. |
| 마을 광장 | 광장 | 게시판과 모닥불이 있는 마을 한가운데. |
| 목공소 | 시설 | 서연의 작업장. 목재 냄새가 가득해요. |
| 가구점 | 상점 | 목공소 안 복희 할머니의 가구점. 집 안에 둘 가구와 러그를 팔아요. |
| 마법사의 탑 | 시설 | 마법 부여대에서 장비에 마법을 부여해요. 마력석이 필요해요. |
| 바닷가 부두 | 자연 | 하준이 낚시하는 곳. 바다 위에 지은 하준네 집 데크 끝이에요. |
| 광산 | 자연 | 아직 안으로 들어갈 수는 없어요. 광맥은 마을 곳곳의 바위 사이에서 나요. |
| 도윤네 | 집 | 잡화점 뒤 도윤의 집. |
| 서연네 | 집 | 목공소 옆 서연의 집. |
| 하준네 | 집 | 호숫가 가까운 하준의 집. |
| 지아네 | 집 | 지아의 집. |
| 민재네 | 집 | 목장 뒤 민재의 집. 아침마다 동물들 소리에 깨요. |
| 해솔네 | 집 | 밭 뒤 해솔의 집. 마루에 늘 말린 옥수수가 걸려 있어요. |
| 은호네 | 집 | 대장간 건너편 은호의 집. |
